# 实时天气查询技能

当用户询问某个城市当前的天气、气温或者天气状况时，
按照以下流程处理。

## 执行步骤

1. 从用户问题中识别城市名称。

例如：

- "南京今天天气怎么样？" → 南京
- "上海现在多少度？" → 上海
- "北京天气怎么样？" → 北京


2. 调用 `get_weather` 工具。

参数：

- `location`：城市名称
- `unit`：默认使用 `c`


例如：

get_weather(
    location="上海",
    unit="c"
)


3. 天气属于实时数据。

禁止根据模型自身知识猜测当前天气。

必须以 `get_weather` 工具返回的数据为准。


4. 获取工具结果后，使用简洁自然的中文回答用户。

例如工具返回：

城市：上海
天气：多云
温度：31℃
更新时间：2026-09-22T16:54:11+08:00

最终可以回答：

上海当前天气为多云，气温约31℃。
