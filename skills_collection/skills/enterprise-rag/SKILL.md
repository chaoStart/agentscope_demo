# 企业知识库查询

## 使用场景

当用户询问：

- PLC 产品
- SC8000
- SC231AW
- 产品手册
- 企业内部技术文档
- 公司知识库内容

应使用本技能。

## 执行流程

1. 分析用户真实问题。

2. 如果问题涉及企业内部知识，
调用 `search_rag` 工具。

3. 将完整用户问题作为 query 参数。

例如：

search_rag(
    query="SC231AW有哪些主要功能？"
)

4. 必须基于 RAG 返回内容回答。

5. 不得根据大模型自身知识虚构企业内部资料。
